# Evaluation rubric

Score each 0-4. A score is a diagnostic, not a forecast.

| Dimension | 0 | 2 | 4 |
|---|---|---|---|
| Audience precision | No identifiable viewer | Broad audience with some context | Exact state, tension, and vocabulary |
| Hook clarity | Confusing/no contract | Topic is clear | Immediate, credible reason to continue |
| Promise integrity | Misleading | Mostly delivered | Payoff clearly equals/exceeds promise |
| Specificity | Platitudes | Some examples | Concrete details, constraints, language |
| Novelty/reframe | Fully familiar | New packaging | Useful surprise or distinct evidence |
| Structural momentum | Stalls | Mostly progresses | Every beat pays or advances |
| Visual function | Decorative/unclear | Some support | Proof/progress/contrast throughout |
| Audio/delivery fit | Distracting | Serviceable | Intelligible and emotionally coherent |
| Emotional resonance | Flat | Recognizable | Precise feeling with earned impact |
| Utility/retrieval | No use later | Some tips | Clearly saveable/reusable tool |
| Social currency | No reason to share | Some identity value | Viewer knows exactly whom/why to share |
| Credibility | Unsupported | Plausible | Evidence, limits, honest provenance |
| Platform packaging | Generic export | Mostly adapted | Native packaging and CTA |
| Originality/ethics | Copies/manipulates | Familiar but safe | Mechanism transformed into authentic work |

Interpretation:
- 48-56: strong draft, test variants.
- 38-47: viable but fix the lowest dimensions.
- 28-37: format-content mismatch or weak proof.
- Below 28: rebuild from audience tension and source asset.

## Red flags regardless of total

- Claim cannot be supported.
- Hook and payoff mismatch.
- Invented personal story/result/credential.
- Distinctive source script copied.
- Harmful stereotype or shame.
- CTA asks for an action unrelated to delivered value.
- Text cannot be read in its screen time.

## Test design

Change one variable per variant:
- Hook framing.
- First visual.
- Length/compression.
- Proof order.
- CTA.
- Delivery energy.

Track at minimum: viewed vs swiped, early retention, average watch time, completion, rewatches, shares, saves, qualified comments, follows/profile visits, and the target business/community outcome. Compare within similar audience and distribution conditions. Do not diagnose from views alone.
