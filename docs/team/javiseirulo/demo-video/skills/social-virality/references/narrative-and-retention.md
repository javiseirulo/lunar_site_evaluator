# Narrative and retention

## The retention chain

Each beat should answer one question and create the next:

1. Contract: why this matters now.
2. Orientation: minimum context.
3. Progress: evidence, point, action, or complication.
4. Turn: contrast, escalation, mistake, reveal, or reframe.
5. Payoff: promised answer/result/emotional release.
6. Residue: a memorable line, next action, or honest invitation.

A beat that neither pays off nor advances can usually be cut.

## Structures

### List
Hook -> point 1 gives immediate value -> points escalate or diversify -> synthesis -> optional save cue.
Do not hide the strongest point last by default. A strong early reward earns later attention.

### Problem-solution
Recognizable symptom -> why common fixes fail -> mechanism -> demonstrated action -> conditions/limits.

### Myth correction
State belief fairly -> show counterevidence or exception -> explain mechanism -> define when old advice still applies.

### Relatable scene
Specific situation -> recognizable micro-behavior -> escalation -> emotional/comedic recognition -> short exit.

### Opinion
Claim -> concrete example -> reason/mechanism -> strongest objection -> bounded conclusion.

### Transformation
Outcome glimpse -> prior state -> obstacle -> decisive change -> evidence -> lesson with limits.

### Story
Cold open at tension/turn -> minimal setup -> complication -> choice -> consequence -> meaning.

## Pace

Pace is information change, not cut count.

Increase pace with:
- Shorter clauses.
- Visual progression.
- Removing duplicated setup.
- Alternating claim and proof.
- Compressing transitions.

Slow down for:
- Emotional weight.
- A complex causal idea.
- Proof the viewer must inspect.
- A line meant to land.

## Looping

Use a loop only when rewatch adds value: a circular sentence, a transformation that resets, or an ending that reframes the first image. Do not cut mid-sentence merely to inflate replay.

## Payoff integrity

The payoff must equal or exceed the hook's promise. If it cannot, weaken the hook or strengthen the content. Satisfaction protects trust, follows, and long-term distribution even when a deceptive open loop might increase short-term watch time.
